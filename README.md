# Old Faithful Eruption GMM Analysis

## Overview
This repository contains the analysis and predictive modeling of the Old Faithful geyser eruption patterns using a Gaussian Mixture Model (GMM). The study is based on historical eruption data and employs the Expectation-Maximization (EM) algorithm to understand the underlying components of eruption duration and intervals.

## Project Structure

- `data/`: This folder contains the dataset of the geyser eruptions.
- `notebooks/`: Jupyter notebooks with exploratory data analysis and model training.
- `src/`: Source code for the GMM implementation and any additional analysis tools.
- `results/`: Generated reports, graphs, and model output files.
- `requirements.txt`: The required libraries and dependencies to run the project.
